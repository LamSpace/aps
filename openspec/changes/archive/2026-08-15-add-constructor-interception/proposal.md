## Why

APS can intercept every non-final instance method but has no hook at object *creation* time. Frameworks that need to register a newly-created instance, inject a back-reference, or validate/veto constructor arguments currently wrap every `proxy()` call in a manual factory — boilerplate this change removes by adding a constructor interception hook analogous to CGLib's `Enhancer` constructor callback.

## What Changes

- Add a new `ConstructorInterceptor` interface with two methods: `before(Constructor<?>, Object[])` (runs before the superclass constructor, may rewrite arguments or veto by throwing) and `after(Object, Constructor<?>, Object[])` (runs after, observational, default no-op).
- Add `proxy()` overloads that accept a `ConstructorInterceptor` for **class proxies only**: `proxy(Class<T>, Interceptor, ConstructorInterceptor)`, `proxy(Class<T>, ConstructorInterceptor, Group...)`, and `proxy(Class<T>, Object[], ConstructorInterceptor, Group...)`.
- The generated subclass constructor emits hook bytecode only when interception is enabled; the `Constructor` object is resolved once in `<clinit>` into a static field.
- The proxy-class cache key gains a single boolean flag (`ctorIntercept`) — the generated class stays interceptor-instance-agnostic.
- The non-intercepted constructor path's generated bytecode remains **byte-for-byte unchanged** (zero regression).

## Capabilities

### New Capabilities

- `constructor-interception`: hooks that run user code before and after a class proxy's superclass constructor, with argument rewriting and veto support.

## Impact

- **Code:** new `io.github.lamspace.ConstructorInterceptor`; changes to `io.github.lamspace.AcceleratedProxy` (overloads, cache key, instantiation path) and `io.github.lamspace.generator.ClassGenerator` (hook bytecode, `<clinit>` constructor lookup).
- **API:** three new additive `proxy()` overloads; no breaking changes to existing signatures.
- **Tests / benchmarks:** new `ConstructorInterceptionTest` and a JMH `ConstructorInterceptionBenchmark`; existing class/interface proxy numbers must not regress.
- **Docs:** `README.md`/`README_CN.md`, `docs/aps-future-roadmap.md`, `docs/benchmark-results.md`/`_cn`.
