# 13. Performance & Benchmarking

APS's whole design — hashCode dispatch + direct `INVOKESPECIAL` — exists to make the hot path as cheap as a direct call. This chapter summarizes what the JMH benchmarks show and how to reproduce them.

## Headline results

- **Class proxies beat CGLib by ~3–5×** on scenarios with actual work; unmatched
  methods (passthrough) run at direct-call speed.
- **Interface proxies** run at parity with `java.lang.reflect.Proxy` and are **~6× faster** on default methods (via `invokeSuper` vs the JDK's
  `InvocationHandler.invokeDefault`).
- **Multi-interceptor (`Group`) adds zero overhead** over the single-interceptor API — the generated bytecode is identical apart from the field name.
- **Annotation-driven interception reaches hand-written-lambda parity** (the
  `@Around` method is bound via a `LambdaMetafactory` call site, not per-call reflection).

Full numbers, methodology, and machine/JDK details: [Benchmark Results](../benchmark-results.md).

## Benchmark suite

Benchmarks live in `src/test/java/io/github/lamspace/benchmark/`:

| File                               | What it measures                                                                                                                                       |
|------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------|
| `ProxyBenchmark`                   | class/interface proxies across return types, parameter counts, standard scenarios, multi-interceptor, multi-interface, default methods, annotation API |
| `ConstructorInterceptionBenchmark` | per-instance construction cost of the constructor hook                                                                                                 |
| `StaticMethodProxyBenchmark`       | static shadowing vs the reflection floor                                                                                                               |
| `RebindBenchmark`                  | cost of swapping interceptors on a live instance                                                                                                       |

## Running the benchmarks

```bash
mvn -s /home/lam/repo/settings.xml clean test-compile
mvn -s /home/lam/repo/settings.xml dependency:build-classpath -Dmdep.outputFile=cp.txt -DincludeScope=test
java --enable-native-access=ALL-UNNAMED \
     --add-opens java.base/java.lang=ALL-UNNAMED \
     -cp "target/classes:target/test-classes:$(cat cp.txt)" \
     org.openjdk.jmh.Main "io.github.lamspace.benchmark"
```

The suite defaults to `AverageTime` / nanoseconds, 3 warmup + 5 measurement iterations of 1 s each, single fork (see the `@Warmup` / `@Measurement` /
`@Fork` annotations on each class).
