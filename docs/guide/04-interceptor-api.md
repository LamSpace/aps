# 4. Interceptor API

## The `Interceptor` interface

```java
@FunctionalInterface
public interface Interceptor {
    Object intercept(Object proxy, Method method, Object[] args) throws Throwable;
}
```

Every intercepted call invokes this method. The three arguments:

| Argument | Meaning                                                               |
|----------|-----------------------------------------------------------------------|
| `proxy`  | the proxy instance (`this` as seen by the caller)                     |
| `method` | the `java.lang.reflect.Method` being called (metadata + dispatch key) |
| `args`   | the boxed arguments; empty array for no-arg methods                   |

The return value is unboxed/cast by the generated bytecode to match the declared return type (`null` for `void`, boxed for primitives).

## Calling the original method

Use `AcceleratedProxy.invokeSuper`:

```java
Greeter proxy = AcceleratedProxy.proxy(Greeter.class, (obj, method, args) ->
        AcceleratedProxy.invokeSuper(obj, method, args));
```

`invokeSuper` asks the proxy's generated `dispatch()` method to jump to the original `super.method(...)` — a direct `INVOKESPECIAL` with no reflection.

## Argument and return handling

- **Primitives** are auto-boxed before your interceptor runs and auto-unboxed after it returns. `int` arrives as `Integer`, etc.
- **`void`** methods: your interceptor's return value is discarded.
- **Reference returns**: the generated code inserts a `CHECKCAST` to the declared type, so returning an incompatible object throws `ClassCastException`.

```java
// Rewrite an argument before the real call
Echo proxy = AcceleratedProxy.proxy(Echo.class, (obj, method, args) -> {
    args[0] = "[" + args[0] + "]";
    return AcceleratedProxy.invokeSuper(obj, method, args);
});
```

## Exceptions

- **`RuntimeException`** and **`Error`** thrown by your interceptor (or the original method) propagate unchanged.
- A **checked exception** is wrapped in
  `java.lang.reflect.UndeclaredThrowableException` (the generated overrides do not declare checked exceptions).

If you need the original checked exception, unwrap it from
`UndeclaredThrowableException.getCause()`.
